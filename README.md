# Mandala VR

Version Meta Quest 3 de Mandala Studio, faite avec Godot 4.6 et OpenXR.

Commandes : joystick gauche pour voler, gâchette droite pour dessiner, A/B/X/Y pour changer genre, palette, relief et couleurs. Le détail s'affiche dans le casque au démarrage.

L'APK se compile sur GitHub (onglet Actions) et se publie dans la section Releases sous le nom `derniere-version`.
